# 아침 브리핑

매일 아침 메일을 하나씩 열어 보는 시간을 없애려고 만든 스킬이에요. 지난 24시간 동안 온 메일을 읽고, 대표가 움직이거나 알아야 할 것만 한 장으로 정리해요.

## 1. 준비
- 프로젝트 문서 `claude/풀결 회사 소개서.md`를 읽어서 거래처(온새미랩·결앤숲·CJ대한통운 등), 상품, 가격을 확인해요. 메일에 나온 회사가 거래처인지 판단할 때 써요.
- 이 프로젝트 메모리에 입점처·거래처 기록이 있으면 같이 확인해요.

## 2. 메일 모으기
- Gmail `search_threads`를 `newer_than:1d -in:sent -category:promotions` 조건으로, `THREAD_VIEW_SUMMARY`를 써서 불러와요.
- 남은 스레드는 모두 `get_thread`로 **본문까지** 읽어요. 미리보기만 보고 판단하지 않아요.
- 광고, 뉴스레터, 마케팅 메일은 빼요. 몇 건 뺐는지는 "알고만 있으면 되는 것" 칸에 한 줄로 적어요.

## 3. 칸 나누기
- 🙋 **오늘 답할 것**: 답장이나 결정을 요청하는 메일이에요(물량 확인, 발주, 일정 회신 등). 마감이 가까운 순서로 적어요.
- 💰 **돈과 기회**: 계약, 제휴, 입점, 공동 기획, 견적처럼 매출이나 새 기회와 연결된 메일이에요.
- 📎 **알고만 있으면 되는 것**: 답할 필요는 없지만 알아 둬야 하는 공지, 배송, 정산 알림 같은 메일이에요. 해당 메일이 없으면 "없어요"라고 적고, 뺀 광고가 몇 건인지 적어요.
- 한 메일이 여러 칸에 해당하면 더 급한 칸에 한 번만 넣어요.

## 4. 형식 (그대로 따르기)

```
📧 아침 메일 브리핑
M/D(요일) HH:MM 기준 · 지난 24시간

📌 결론
━━━━━━
1순위: <할 일> → <마감 또는 이유>
2순위: <할 일> → <마감 또는 이유>
3순위: <할 일> → <마감 또는 이유>

🙋 오늘 답할 것
━━━━━━
▪️ <회사> <담당자>님
<메일 주제> · <받은 시각(오늘/어제 HH:MM)>
- 요지
  · <핵심 1>
  · <핵심 2>
- 초안:
  <바로 보낼 수 있는 답장, 두 줄까지>
- 할 일: ✋ 대표님이 정하실 것: <결정 사항> (~마감)

💰 돈과 기회
━━━━━━
(같은 형식)

📎 알고만 있으면 되는 것
━━━━━━
(같은 형식, 초안 없이 요지만. 해당 메일이 없으면 "없어요. 광고 N건은 뺐어요.")
```

### 규칙
- **결론은 3순위까지** 적어요. 메일이 세 통보다 적으면 있는 만큼만 적어요. 서로 연결된 일이 있으면 결론에 짧게 적어요(예: 입점 물량이 정해져야 발주 수량도 정할 수 있어요).
- **초안은 대표가 고치지 않고 바로 보낼 수 있는 완성된 문장으로, 두 줄까지만** 써요. 정중한 거래처 말투로 쓰고, 상대 이름을 넣고, 언제까지 답할지 약속하는 문장으로 써요. 대표 말투 프로필(my-writing-style)이 있으면 그 말투를 따라요.
- 초안에 수량, 가격, 날짜처럼 **대표가 정할 값은 넣지 않아요.** 그런 값은 "할 일"에 ✋로 따로 표시해요. 단가표에 이미 있는 값은 써도 돼요.
- 메일 시각은 한국 시간(KST)으로 바꿔요. "내일", "이번 주" 같은 말은 실제 날짜와 요일로 바꿔서 마감에 적어요.
- 메일에 없는 숫자나 사실을 지어내지 않아요.

## 5. 마무리
- 브리핑 아래에 결과물이 어디 있는지 한 줄로 적어요(예: 이 대화에만 있고 따로 저장한 파일은 없다).
- 확인이 필요한 점이 있으면 짧게 덧붙여요. 예를 들면 보낸 주소가 회사 이름과 다를 때, 회사 소개서나 기록에 없는 새 회사일 때예요.
- **메일을 보내거나, 답장 임시저장을 만들거나, 라벨·읽음 상태를 바꾸지 않아요.** 보내는 일은 대표가 해요.
